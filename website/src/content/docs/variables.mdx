A variable is a live value wrapped in dollar signs: `$player.name$`, `$player.stat.strength$`,
`$time.season$`. It works in:

- **text** — item lore, menu names, messages, the scoreboard: `"<gold>Coins: $economy.purse$"`
- **formulas** — ability damage, enchant bonuses, XP curves: `"50 + $player.stat.strength$ * 2"`
- **conditions** — `$player.hp$ > 50`

A variable that doesn't apply (no target, not in a menu, unset) is empty: text shows nothing, maths
treats it as 0, and `== null` is true. Whole numbers are shown without decimals (`100`, not
`100.0`).

<Callout type="warning" title="Dollar signs in text">
Every `$` starts a variable, so plain text can't contain a lone `$` — `"Costs $5"` breaks the rest
of the line. Write `5 coins` instead.
</Callout>

## Your own variables

`player.var.<name>` stores any value on the player's profile, saved with their data:

```yaml
- "variable set player.var.class warrior"
- "variable add player.var.dungeon_runs 1"
- "counter increment player.var.kills"
```

Read it back as `$player.var.class$`. A quest `variable` objective can wait for one to reach a
number. `variable remove player.var.class` deletes it.

## Test a variable in-game

```text
/valmora variable get $player.stat.strength$
```

prints what a variable resolves to for you right now.
