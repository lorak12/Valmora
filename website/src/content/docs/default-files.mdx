Valmora seeds ~138 files on first run and **never overwrites** existing files (tracked by
`plugins/Valmora/.resources_seeded`). For the folder map and reload rules, see
[Folder layout](/docs/file-layout) and [config.yml](/docs/config-yml).

## Root files

<RefTable kind="shippedFiles" />

Single-file configs: `config.yml`, `plugin.yml`, `ui.yml`, `rarities.yml`, `item_types.yml`,
`mob_categories.yml`, `entity_categories.yml`, plus the empty-by-default pipelines
`combat_pipeline.yml`, `item_pipeline.yml`, `mob_pipeline.yml`, `resource_pipeline.yml`,
`fishing_pipeline.yml`, `death_pipeline.yml`.
