Events are the "do something" lines in quest rewards, menu buttons, NPC clicks, abilities and
everywhere else. How to write them — options like `delay:`, quoting, and who "the player" is — is
on the [Scripting overview](/docs/scripting). In the syntax column, `<x>` is required, `[x]` is
optional, and `a|b` means one of.

Where an event takes a **selector** (`@self`, `@target`, `@enemies_in_radius{r=5}`…), see
[Target selectors](/docs/target-selectors).

## Examples

```yaml
# a quest objective reward
events:
  - "notify <gold>Quest complete! category:quest_complete"
  - "economy_add 500"
  - "point reputation add 10"
  - "tag add helped_the_village"
  - "sound player entity.player.levelup"

# a menu button that costs coins
actions:
  LEFT:
    conditions:
      - "$economy.purse$ >= 1000"
    actions:
      - "economy_remove 1000"
      - "give ENCHANTED_GOLDEN_APPLE:1"
    fail-actions:
      - "notify <red>You need 1,000 coins."

# a server-wide announcement from a calendar event
on-start:
  - "notifyall <gold>The Harvest Festival has begun! io:title"
  - "foreach @all give BREAD:16"
```
